# CRM Frontend

یک پروژه فرانت‌اند برای سیستم مدیریت مشتریان (CRM) با استفاده از React و Vite

## ویژگی‌ها

- **احراز هویت**: ورود و ثبت نام کاربران
- **داشبورد**: نمایش آمار و لیست مشتریان
- **مدیریت معاملات**: پیگیری فرصت‌های فروش به صورت Kanban
- **مدیریت وظایف**: ایجاد و پیگیری کارها
- **طراحی واکنش‌گرا**: سازگار با موبایل و دسکتاپ
- **پشتیبانی از RTL**: طراحی راست‌چین برای زبان فارسی

## تکنولوژی‌های استفاده شده

- **React 19** - کتابخانه UI
- **Vite** - ابزار ساخت و توسعه
- **React Router** - مسیریابی
- **Tailwind CSS** - استایل‌دهی
- **Lucide React** - آیکون‌ها
- **Axios** - درخواست‌های HTTP

## نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه تولید
npm run build

# پیش‌نمایش نسخه تولید
npm run preview
```

## صفحات

### 1. ورود (Login)
- فرم ورود با ایمیل و رمز عبور
- اعتبارسنجی ورودی‌ها
- نمایش خطاها

### 2. ثبت نام (Register)
- فرم ثبت نام با نام، ایمیل و رمز عبور
- تأیید رمز عبور
- اعتبارسنجی کامل

### 3. داشبورد (Dashboard)
- کارت‌های آمار (کل مشتریان، مشتریان فعال، مشتریان جدید)
- جدول لیست مشتریان
- جستجوی مشتریان
- عملیات CRUD

### 4. معاملات (Deals)
- برد Kanban برای پیگیری مراحل فروش
- فیلتر بر اساس وضعیت
- آمار معاملات
- نمایش ارزش کل معاملات

### 5. وظایف (Tasks)
- لیست وظایف با وضعیت‌های مختلف
- فیلتر بر اساس وضعیت
- نمایش اولویت‌ها
- تاریخ سررسید

## اتصال به Backend

برای اتصال به بک‌اند، آدرس API را در فایل `src/services/api.js` تنظیم کنید:

```javascript
const API_BASE_URL = 'http://localhost:3001/api';
```
